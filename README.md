# Лабораторная работа № 7: Работа с базами данных через JDBC

## **Автор:** Дабагян Кристина Кареновна
## **Группа:** ФИТ-251

## Описание
В работе реализовано подключение к встроенной базе данных **H2** (в памяти) через JDBC. Выполнены SQL-запросы (SELECT, INSERT, UPDATE, DELETE), создание и удаление таблиц, а также загрузка уникальных данных из JSON-файла.

## СУБД
**H2 Database** (встроенная, не требует установки сервера).

## Подготовка базы данных
Перед запуском убедитесь, что в ресурсах или в корне проекта лежат файлы:
- `music-create.sql` — скрипт инициализации схемы `study` и таблицы `music`.
- `books.json` — данные посетителей и книг из ЛР №5.

Таблицы для книг и посетителей создаются программно при первом запуске.
