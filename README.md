### Формат текстового файла

Одна строка — одна фигура. Разделитель — `;`.
Пустые строки и строки, начинающиеся с `#`, игнорируются.
CIRCLE;<radius>
RECTANGLE;<width>;<height>

Пример:
CIRCLE;3.5
RECTANGLE;4;6

### Поведение при ошибках в текстовом файле

Некорректная строка **пропускается** с предупреждением в stderr.
Уже прочитанные фигуры сохраняются в списке (частичная загрузка).

### Запуск
java -cp out app.Main data/figures.txt data/figures.bin

Без аргументов пути запрашиваются у пользователя.

### Пакеты

- `main.java.geometry2d` — интерфейс `Figure`, классы `Circle`, `Rectangle`
- `main.java.geometry3d` — класс `Cylinder`
- `main.java.exceptions` — собственные исключения
- `main.java.storage` — интерфейс `FigureStorage` и две реализации
- `app` — точка входа `Main`
