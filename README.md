## Описание проекта
В данной работе реализованы базовые задачи на языке Java (JDK 25), демонстрирующие работу с примитивными типами данных, вещественной арифметикой, побитовыми операциями, строками и массивами.

### Основные особенности реализации:
- **Без коллекций:** Использовались только примитивы и массивы.
- **Без исключений:** Обработка ошибок реализована через проверки условий (`if-else`).
- **Архитектура:** Каждое задание вынесено в отдельный пакет и класс. Точка входа — класс `Main`.
- **Меню:** Реализовано интерактивное консольное меню с использованием `switch` (нового синтаксиса `->`).

---

## Что реализовано (Задания)
1.  **Целочисленные ловушки:** Демонстрация переполнения, особенностей типов `byte`, `int`, `long` и арифметики `char`.
2.  **Вещественная арифметика:** Ошибки точности `double`, сравнение с `epsilon`, работа с `NaN` и `Infinity`.
3.  **Побитовые операции:** Работа операторов `&`, `|`, `^`, `~` и сдвигов `>>`, `>>>`.
4.  **Обработка текста:** Проверка на палиндром, реверс слов, шифр Цезаря и поиск длинного слова.
5.  **Одномерные массивы:** Случайное заполнение, поиск статистики и ручная реализация сортировки "Пузырьком".
6.  **Многомерные массивы:** Вывод матриц, транспонирование и умножение.
7.  **Методы и аргументы:** Перегрузка методов, использование `varargs`, сравнение итеративного и рекурсивного возведения в степень.
8.  **Консольное меню:** Цикл `do-while` и текстовые блоки `"""`.
9.  **Сборка проекта:** Ручная сборка через терминал и скрипты автоматизации.

Инструкция по сборке и запуску  
Способ 1: Использование скрипта  
Если вы используете Windows, запустите:  
build.bat  


Если вы используете Linux/macOS:  
bash build.sh  


Способ 2: Ручная сборка через терминал  

Компиляция:  
javac -d out -sourcepath src src/ru/university/lab2/Main.java  


Создание JAR-файла:  
jar cfm Lab2.jar manifest.mf -C out .  


Запуск:  
java -jar Lab2.jar  


Технологии  
Java 25 (LTS)  
Манифест для указания Main-Class.  
Сборка без использования сред разработки (IDE автоматизации).
