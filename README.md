## Описание работы
Программа читает список посетителей библиотеки из файла `books.json`, используя библиотеку **Gson**. 
Для обработки коллекций применяется **Stream API**. Стандартные методы классов (геттеры, сеттеры, 
`toString`, `equals`, `hashCode`) генерируются с помощью **Lombok**.

## Стек технологий
* Java 25 LTS
* Maven
* Gson (для парсинга JSON)
* Lombok (для генерации boilerplate-кода)
* Stream API (для фильтрации, сортировки и группировки данных)
