# Лабораторная работа № 8: Принципы SOLID

## **Автор:** Дабагян Кристина Кареновна
## **Группа:** ФИТ-251

## Описание
В работе проведен рефакторинг кода для демонстрации пяти принципов SOLID:
1. **SRP** — разделение обработки заказа и отправки уведомлений.
2. **OCP** — добавление новых фигур без изменения `ShapeDrawer`.
3. **LSP** — разделение интерфейсов для транспорта.
4. **ISP** — разделение интерфейсов для принтеров/сканеров.
5. **DIP** — внедрение зависимости `Storage` в `Computer`.
